# 로봇 사양과 출처

## Generic 6-Axis (synthetic)
자체 제작 기능 검증 모델이다. HITBOT 및 다른 실제 제품의 치수·제한·동역학 사양이 아니다.
모델의 모든 길이, 관절 범위와 속도는 테스트 설정이며 실제 장비에 사용하지 않는다.
`data/robots/generic_6axis/robot.urdf`에 원점을 명시한다. 축 순서 Z/Y/Y/X/Y/X,
관절 원점 이동 (m): (0,0,.18), (0,0,.12), (.32,0,0), (.28,0,0), (.09,0,0), (.09,0,0).
flange 고정 이동 (.07,0,0), tool0는 flange와 일치한다.
제로 자세 TCP는 (.85,0,.30)m이다. 질량/관성/가속도/payload는 지정하지 않으며
동역학을 지원한다고 표시하지 않는다. URDF velocity/effort도 합성 테스트 값이다.

## HITBOT Z-Arm S922
이 프로젝트에서 검증 완료한 기구학/동역학 파라미터는 아직 없다.
로컬 HITBOT 폴더에 제조사 매뉴얼과 기존 웹 스튜디오가 있으나 해당 웹 모델의 문서는
근사 DH/영점을 명시한다. S622 자료를 S922 사양으로 사용하지 않는다.
제조사 자료는 공개 배포 권한이 확인되지 않아 저장소에 복사하지 않는다.

확보 및 대조할 자료:
1. 정확한 S922 모델/리비전/제어기 펌웨어와 정식 URDF 또는 축별 CAD.
2. 관절 원점·축·방향·제로 오프셋·보정값 및 관절 제한.
3. 최대 관절 속도/가속도, 링크 질량·관성, payload 및 무게중심 한계.
4. base/flange 도면과 장착 방향, tool/TCP 캘리브레이션.
5. visual/collision mesh의 단위와 원점, 배포·사용 권한.
6. 제어 언어, PTP/MoveL/MoveC 보간·blending·단위·Euler 규약 및 I/O 사양.
7. 제조사 FK 기준 자세/좌표와 현장 검증 절차.

위 자료가 검증되기 전 S922 모델 선택·장비용 코드 출력은 제공하지 않는다.
